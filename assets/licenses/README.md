# Asset provenance

The six GLB meshes were generated locally by tools/blender/generate_vehicles.py
using Blender primitives and original code. No external model or texture was
imported; no War Thunder/World of Tanks/Sketchfab assets were used.
These blockouts are project-generated assets; no third-party asset licence
obligations attach to them. Repository-wide licensing remains the owner's
choice (no blanket licence is assigned here).

Research photograph/drawing URLs are in docs/references. No reference photographs
are redistributed in this repository. Validation PNGs are renders of our own
blockouts, not source photographs. Source provenance does not imply model
historical accuracy: current assets fail the stricter fidelity acceptance.
