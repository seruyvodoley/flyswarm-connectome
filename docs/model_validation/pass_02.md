# Geometry pass 02 — intermediate, not historical acceptance

2026-09-16. Tiger I now uses a dedicated original Blender source and component
references documented in ../references/tiger_i/modelling_pass_02.md. It has a
rounded asymmetric turret, paired steel wheels, separate sprocket/idler, combat
tracks, mantlet, open brake, engine deck and exhaust fittings. LOD0 has 224,036
triangles: above the intended budget; optimisation and manually reviewed LODs
remain outstanding. Overall tolerances are NOT passed.

The other five assets received an accelerated recognition pass, not a completed
reference-led reconstruction. Panther has an angular welded turret and curved
mantlet; Jagdpanther an integrated tall sloped casemate; T-34-85 and IS-2 have
different ring-built cast turret profiles and five/six road-wheel stations;
SU-100 has a lower forward casemate and offset gun. All now have straight ground
track runs, rounded ends, wheel dishes/hubs, engine deck fittings and distinct
gun/brake arrangements. These features remain provisional, particularly factory
variants, wheel offsets, mantlets, roof fittings and longitudinal dimensions.

The existing source packs remain incomplete. Museum pages for Panther,
Jagdpanther and T-34-85 were rechecked; surviving/postwar examples are not
silently treated as exact late-1944 production references. See each references.md.
No historical validation PASS or finished photorealistic asset is claimed.

Regeneration: run tools/blender/build_tiger_late.py for Tiger; run
 tools/blender/generate_vehicles.py for the remaining five (Tiger is protected).
Neutral views are generated by validate_vehicle_dimensions.py. Static track
links are visual geometry; terrain marks are the existing bounded pressure/slip
approximation, not a deformable-terrain solver. Tiger contact spacing and width
now match its independently sourced combat-track dimensions.
