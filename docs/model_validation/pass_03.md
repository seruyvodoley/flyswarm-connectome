## Limits

This is a reconstruction pass, not a claim of complete historical acceptance. Component placement and several dimensions remain photo-interpreted/provisional. Full independent dimension sheets and side/front/top alignment are still missing. No verified 2–3% tolerance PASS is claimed. T-34 target is now Factory 112 because the inspected museum vehicle has documented provenance. Modelled running gear differs between Panther, T-34 and IS families; Tiger remains untouched.

Manual LOD variants are not supplied; Godot import LODs remain enabled. No texture images are included. Some meshes exceed the preferred polygon budget after bevels. Scale, mantlet detail, wheel profiles, cupola detail and secondary fittings still require refinement.
