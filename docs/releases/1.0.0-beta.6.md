# FlySwarm 1.0.0-beta.6 — Open Day session lifecycle

This macOS arm64 beta fixes stale Open Day battles returning after the result,
help, replay, or menu navigation flow. Each new match starts a fresh session and
tears down the previous battle cleanly.

## Changes

- Completed battles stop processing, disconnect their simulation bridge, and
  cannot be resumed. “Play again” creates a new match while keeping the selected
  vehicle.
- Open Day matches choose among 12 clear spawn layouts. Player and fly always
  start 416 m apart, with the village/terrain blocking initial line of sight.
- Vehicle heading is aligned toward the opposing spawn in each layout.
- Added automated route regression coverage for result/help/menu/restart paths,
  pending-load cancellation, and spawn separation/visibility.

## Validation

- Source GUI route validation: 0 failures.
- Exported application resource validation: 0 failures.
- DMG image verification and strict code-signature verification passed.
- A copy launched from the mounted DMG outside the checkout reached the Open Day
  menu and a live MaleCNS battle; motion, firing and damage were observed.

The application is ad-hoc signed and is not notarized. The MaleCNS model remains
included under its previously verified redistribution terms.
