# FlySwarm Connectome 0.2.0-beta.1

This Apple Silicon beta bundles the Godot application and a relocatable
arm64 Python backend. Open Day now advances its 50 Hz world physics
independently of asynchronous MaleCNS responses and holds only the latest
validated motor command between neural ticks. Neural telemetry is updated only
when a new backend response arrives; research and training retain their
synchronous two-brain `batch=8` path.

The MaleCNS dataset is not included. In Settings, choose the folder containing
the compatible `brain.npz` and `weights.npz` files and run **Check MaleCNS
data**. The app validates both files against the installed FlyBrain release
before enabling the demo. The dataset remains on the user's computer.

The release targets macOS 13 or later on arm64. It is ad-hoc signed for bundle
integrity, without an Apple Developer ID signature or notarization. Gatekeeper
may show its normal first-open warning. No system security settings are
changed.

Measured real MaleCNS Open Day runs reached approximately real-time pacing;
the near-90-second run ended at 88.82 simulated seconds after 88.83 seconds of
active wall time. The app also records bounded frame, physics, IPC and neural
tick statistics for profiling.

Known limits: this is a beta for Apple Silicon only; users must supply the
separately obtained MaleCNS data; Gatekeeper may require the user to approve
the first launch. This release does not include experimental datasets or
results.
