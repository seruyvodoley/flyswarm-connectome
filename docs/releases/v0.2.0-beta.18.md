# v0.2.0-beta.18

Open Day now uses a mouse-only visitor flow: the cursor sets a world-space
ballistic aim point, the turret and gun slew toward it, left-click fires, and
holding right-click smoothly zooms the third-person camera. The player's tank
drives and repositions automatically. Demo-only health and reload tuning prevent
one crew or module hit from disabling the visitor's tank; all other battle modes
retain the historical damage model.

MaleCNS remains the opponent controller. Its raw neural output, decoded command,
navigation assistance and final action are shown separately, with navigation
intervention measured in the demo HUD and match report. Five complete 90-second
headless matches with the real 166,700-neuron dataset are recorded in
`artifacts/performance/open_day_five_match_validation.json`.

Validation: 28 Python tests, Godot combat and bridge checks, Open Day mouse,
damage and interface checks, and five real MaleCNS matches. Headless validation
does not measure rendered FPS or certify physical Windows GUI behavior.
