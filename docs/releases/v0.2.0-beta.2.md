# FlySwarm Connectome 0.2.0-beta.2

This Apple Silicon beta revises the Open Day tank controls. The tank drives
forward automatically. Mouse movement directly adjusts turret traverse and
gun elevation; it does not steer the hull or make the gun chase a stationary
screen point. Drag with the middle mouse button to rotate the hull separately.
The right mouse button fires. In the gunner camera, the left mouse button
toggles a reduced-field-of-view optic with a graduated reticle. The camera
selector and mouse-wheel camera toggle keep the demo usable without keyboard
vehicle controls.

The gunner reticle is centered on the barrel direction. In the optic it adds a
graduated range grid, outer bezel, and weapon reload/ammunition status. Mouse
vertical motion raises or lowers the gun within the selected vehicle's
elevation limits.

The release is for macOS 13 or later on Apple Silicon (arm64). It bundles the
relocatable Python backend. MaleCNS research data is not included; users choose
their own compatible dataset in Settings. The application is ad-hoc signed for
bundle integrity and is not signed with an Apple Developer ID or notarized.

Validation included the Python test suite, Godot ballistics and bridge checks,
Open Day input and scheduler validation, plus a rendered gunner-optic capture.
