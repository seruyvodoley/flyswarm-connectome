# FlySwarm research protocol

The prespecified question is whether real reconstructed MaleCNS output signals change agent behavior in the Godot 3D environment. The primary measure is terminal ticket balance, `(BLUE tickets − RED tickets) / 600`, with BLUE running the condition under test and RED using the unchanged Rule AI. It is a behavioral outcome, not evidence of biological intelligence.

Each seed is evaluated under every configured condition with the same map seed, normalized symmetric T-34-85 setup, no communication, and both physical-side assignments. The two assignments are averaged within a seed; they are not independent observations. Training, validation, and test seeds must be disjoint. Configure the final test seeds before collecting data and do not tune against them. `MALECNS_REAL` uses the six recorded descending channels. `MALECNS_ABLATED` zeros the explicitly listed descending channels for BLUE after recording the unmodified traces. `MALECNS_SHUFFLED` assigns each BLUE agent the next agent's six-channel output within that team; it preserves the exact channel values at each step while breaking the observation/output identity pairing. `NON_NEURAL_TRAINED` is a required but not yet qualified comparison condition. The currently available ridge checkpoint imitates Rule AI and is **not** an independently trained, task-matched controller. Do not treat it as satisfying this control until a matched training pipeline, disjoint train/validation/final-test seeds, equal model family/capacity and compute budget, and held-out task evaluation are recorded. `RULE_BASED` is the engineering reference. The imitation checkpoint remains preserved as a diagnostic artifact.

Run short pilots only to validate operations. Set the final number of independent seeds from pilot variance and a preregistered power/effect-size calculation; a fixed count is not automatically adequate.
