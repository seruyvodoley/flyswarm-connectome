# Reproducibility and archive format

Every experiment receives a unique UTC timestamp plus random suffix. A run directory is created exclusively and contains the simulator manifest, summary, sampled replay, Godot log, 50 Hz game-state JSONL, and—when MaleCNS is active—one streamed neural-step JSONL. A streamed row records the experiment/run/condition IDs, seed, step, simulation and wall timestamps, exact sensory inputs, observations without teacher labels, raw and intervened neural traces, control layers, actions, and backend metadata. The game-step stream adds actual final actions after Godot auxiliary adjustments, poses, turret/gun state, visibility, module state/damage, impacts, metrics, tickets, and zones.

Backend metadata records FlyBrain version, dataset SHA-256 values, neuron count, batches, instance independence check, neural timestep, seeds, Python/Godot versions, platform, commit, and condition. Godot battle randomness, terrain randomness, visual-effect randomness, and the two FlyBrain seeds are distinct and explicitly seeded. In research mode, a physics step is blocked until its next sequential neural response arrives: simulation time advances by exactly 20 ms per fresh output and never repeats an old action while Python is busy. Interactive play keeps its separate visual zero-order-hold behavior. The protocol fingerprints Godot scripts/scenes, scenario, vehicle models, Python source, research runner, and collection configs. The runner refuses to start or resume a run if that fingerprint differs from the experiment lock; it also checks after a run and preserves changed-source data as invalid diagnostics. Each manifest records full `git status --porcelain`; dirty runs are identifiable and must not be confused with a clean commit. A repeat compares simulation-time inputs, neural outputs, applied controls, game states, projectiles, and authoritative combat events while excluding wall-clock timing fields. Cross-platform bitwise physics identity is not implied.

Raw JSONL is append-streamed. Validation is fail-closed: it does not repair or impute rows. SHA-256 checksums are generated only once and never overwrite an existing checksum file. Processed analysis belongs in `processed/`; raw run files remain unchanged.

## Exact 30-second repeat check (2026-10-18)

`experiment-20261018T164727Z-72fcf668` and `experiment-20261018T171448Z-5d16cdc3` used the same config SHA-256 and source fingerprint (`8575659e39d20db0051a2b0ad543871954774cf3c3e8e7a7b9976c6818dc15d6`). All 16 paired run directories validated. Rule-based traces were exactly repeatable after excluding run IDs and wall-clock fields. Of the four live MaleCNS runs, one was exactly identical; three diverged numerically.

The first detected divergence was in the normal-side seed-61001 MaleCNS run at game step 469 (9.36 simulated seconds): vehicle 2's vertical position differed by 0.00003338 m although the logged action, speed and heading were the same. The next neural observation inherited that position difference at step 470; action values then differed at about the 1e-7 scale. Across the four MaleCNS pairs, maximum observed positional differences were 0, 0.2795, 2.8535 and 4.8685 m. The two larger drifts ended with a different target assignment for agent 10 at 28.68–28.74 s; alive/module flags and normalized combat-event sequences remained the same in these runs. The test therefore does **not** establish exact reproducibility or a defensible tolerance. The earliest drift is consistent with a tiny physics/contact numerical perturbation that is amplified by closed-loop control, but its cause is not yet proven. A tolerance must be justified and fixed before additional comparisons; it must not be selected to accommodate these observed results.

## Exact 60-second repeat check (2026-10-19)

`experiment-20261018T173656Z-5a60960a` and `experiment-20261018T175359Z-b07daf50` used the same 60-second config SHA-256 and source fingerprint (`8575659e39d20db0051a2b0ad543871954774cf3c3e8e7a7b9976c6818dc15d6`); all eight run archives validated. Both Rule assignments and the non-swapped MaleCNS assignment were position/event identical. The swapped MaleCNS assignment diverged first at game step 714 (14.26 s): vehicle 4's x coordinate differed by about 0.000001 m under identical preceding logged commands. The first differing neural observation was step 715. Maximum position divergence reached 5.9929 m by the end. At 28.76 s, vehicle 4 had different visibility/target assignment; later module damage diverged. The two runs each fired 37 shots and had 32 vehicle/world collision records, but the first recorded 3 penetrations and 3 damaging shots while the repeat recorded 5 and 5. No kill occurred in that swapped-side pair. This confirms that the tiny early physics difference can change target selection and combat outcomes during a longer neural-controlled battle. No post-hoc numeric tolerance can make these outcomes equivalent; reproducibility remains a blocker pending diagnosis and a preregistered comparison tolerance.
