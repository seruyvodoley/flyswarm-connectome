# Environment and creature asset sources

The files in this directory are visual assets only. Geometry and textures are bundled locally so the demo does not depend on runtime downloads. Imported GLBs were dequantized for Godot compatibility; scene scale, placement, batching, lighting, and material use are project-side changes.

## Ground materials

Each set contains the 1K diffuse, normal, and roughness maps from Poly Haven. The arena shader blends them into a grass verge, worn soil shoulder, and muddy vehicle lane.
