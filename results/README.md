# Experimental artifacts

Все 25 исходных файлов результатов сохранены побайтно. Их новая раскладка
и SHA-256 перечислены в `docs/file_manifest.json`. Старые имена в `results/`
являются относительными символическими ссылками на новые пути; исторические
скрипты используют их без изменений. Запускать из корня проекта.

- `raw/`: per-step traces и большой подробный DN screen; локальные, не в Git.
- `summaries/`: итоговые и небольшие per-seed таблицы, JSON конфигурации.
  В частности, `flyswarm_04_audio_raw.csv` содержит метрики на бой и полезен
  для воспроизводимости, поэтому сохранён здесь и включён в Git.
- `models/`: три небольших NPZ с training data/readout/OOF predictions.
- `figures/`: место для будущих графиков.
- `tmp/`: временные локальные результаты, не в Git.

На новом clone ссылки на raw-файлы будут без содержимого до восстановления
локальной копии или повторного запуска эксперимента. Каталог raw сохранён
через пустой `.gitkeep`; при запуске исходные скрипты создадут файлы через ссылки.
Git не является резервной копией raw-данных: их нужно копировать отдельно.
Повторный запуск может перезаписать исторический результат через symlink.

Новый неизменённый FlySwarm 0.5 использует собственные legacy пути прямо в
`results/`. Его raw output исключён из Git, summary по умолчанию доступен для
версирования. Smoke test пишет исключительно во временный каталог.
